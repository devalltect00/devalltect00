### 🧪 Recommended Beta Validation

1. Install the beta in an isolated environment.
2. Review configuration and generated templates before using them.
3. Run `custy validate` in a non-production repository.
4. Preview consequential operations with the global `--dry-run` option.
5. Verify files, Git state, tags, remotes, artifacts, and diagnostic logs.
6. Report unexpected behavior before the release advances to RC.
